## 📡 What I build

| | Project | What it does |
|:-:|---|---|
| 📱 | **[Wavelog-Mobile](https://github.com/TA4RX-SP9AQG/Wavelog-Mobile)** | Android app for [Wavelog](https://github.com/wavelog/wavelog). Log QSOs on the go, run contests, chase live DX spots, track DXCC and band/mode stats. *(Dart)* |
| 🔌 | **[WaveRig](https://github.com/TA4RX-SP9AQG/WaveRig)** | ESP32-S3 BLE bridge that connects ICOM CI-V and Yaesu/Kenwood CAT radios to Wavelog Mobile over Bluetooth. |
| 🧩 | **[Wavelog-Last-QSOs-Widget](https://github.com/TA4RX-SP9AQG/Wavelog-Last-QSOs-Widget)** | Embeddable widget that shows your latest QSOs on any website. *(HTML)* |
| 📝 | **[WP-Wavelog-Registration](https://github.com/TA4RX-SP9AQG/WP-Wavelog-Registration)** | WordPress plugin that automates Wavelog account registration, with forms and admin management. *(PHP)* |
| 🛒 | **[WP-Amator-Bitlik](https://github.com/TA4RX-SP9AQG/WP-Amator-Bitlik)** | WordPress plugin for amateur radio gear classifieds with multi-currency support. *(PHP)* |
| 📲 | **[Amator_Bitlik_App](https://github.com/TA4RX-SP9AQG/Amator_Bitlik_App)** | Android companion app for the Amator Bitlik classifieds. *(Kotlin)* |
| 🔑 | **[APRS-Code-Generator](https://github.com/TA4RX-SP9AQG/APRS-Code-Generator)** | Generates the passcode needed to log in to APRS-IS based applications. |
| 🧲 | **[Automatic-MLA-Tuner](https://github.com/TA4RX-SP9AQG/Automatic-MLA-Tuner)** | Automatic antenna tuner for MLA setups. *(C++)* |
